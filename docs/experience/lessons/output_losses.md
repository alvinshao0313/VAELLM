# 输出损失：先校准数值尺度，保留真实目标

## 问题与证据

真实 Qwen3-8B 的3个 up_proj、两种子、每阶段300步、三任务各前256题对照中，MSE均值71.4193%，分组输出56.5755%，AMSE44.1406%。在这些固定条件下，直接替换默认目标没有收益。[原始中文报告](../records/.result/activation_loss_ab/20260922_input32_downstream_v2/REPORT_CN.md)

2026-10-01，真实Qwen3-8B双stage/full rotation的L18/o，以完整原坐标输出MSE、固定decoder、FP32敏感度代理优化两级packed码128步。32个Alpaca训练文档/32独立留出文档上，native训练/留出MSE分别降低74.50%/30.74%，权重MSE却增加62.82%。非码字节、存储位宽及独立重载一致性均通过。这说明有限激活分布上的输出收益可以伴随其他方向误差增大，尚无该配方的整模型准确率结论。[配置、逐步轨迹与原始验证](../records/qwen3_w25/2026-09-30_goal.md)

## 原因与解释边界

真实 Gram 矩阵对角均值在被测层间约为0.0046、0.0625、1.3295；加入 H 不只改变误差方向，也改变重构项相对于固定 BSQ 辅助项的尺度。这个尺度变化有测量证据，但尚未通过独立消融证明它解释了全部掉点。不能据此直接断言“相关性有害”或“校准过拟合”。

上述离散码试验第20次更新集中翻转825万bit，下一步loss升至初始约490.5倍，到第55次前向才重新低于初始，最后仍未证明收敛。实际代理梯度没有下溢，唯一换轮在第128步；同半径初始化与Adam近sign步幅导致同步跨阈值是与轨迹相符的解释。累计翻码2073万次、最终不同码仅179万位，不能把翻码事件数当进步，也不能把最终有收益描述为全程稳定。

同源四投影的32/128/512校准量对照随后完成：512文档的等投影selection误差比最低0.630868，独立confirmation为0.629823；但L27/down的selection和confirmation仍分别恶化4.00%和4.49%。该层512臂训练MSE降低14.89%，第102次更新后却已达到更低训练误差，至128次反弹26.70%；FP32和BF16留出误差比仅相差约0.00010。因此扩大校准集并未消除全部泛化间隙，末端振荡与过拟合也不能互相替代解释。先以相同数据/源模型比较96步截断和半学习率128步；不把另外三个投影改善外推为所有投影均改善。完整证据仍见同一Qwen3专题记录。

在无旋转/INT8保护新底座上，512文档、128step的LR对照仍存在不同失效模式：s/128使L9/gate第88次前向后训练误差反弹约29.90%，留出基本持平；L27/down最低训练误差却在最后一次前向，native训练MSE降低19.27%、完整留出MSE增加4.46%、权重MSE增加52.56%。后者不能归因于末端训练反弹，FP32/native差也不足以解释。四投影等权平均误差改善主要来自attention，不能掩盖MLP无收益而直接推断整模型提升。证据见同一Qwen3专题的 `local_bits_recipe_protected/pilot.json`；此时尚未运行该码字配方的全模型评测。

相同新底座/数据的MLP focused对照进一步表明，s/256、round256的128步端点改善gate/down selection误差约21.26%/6.21%，延至256步却恶化23.51%/25.64%。两臂前128步全部loss/telemetry精确相同，无中途换轮，额外预算使训练末端反弹；不能假设更小LR必需配更长训练。该结果只支持本次两类训练配方的选择，尚无整模型收益证明；来源 `local_bits_focus_protected/summary.json` 见同一专题。

完整36层顺序decoder恢复给出了更强的反例：无旋转/INT8源上，Alpaca前64文档（9635 tokens）、公共64留出文档（9183 tokens）、max256、64step/LR1.25e-5，学生前缀逐层原生推进，目标始终来自独立原始teacher。36/36块的native训练和留出MSE都降低，但同一全量八任务均分从60.8495%降至53.1350%，MMLU从51.2961%降至39.5955%；位宽、非decoder字节和独立重载均通过。它证明该配置的局部/同分布留出改善不能替代全模型跨任务验证，尚不能单独区分校准分布、有限样本、目标不匹配或参数容量的原因。该64步配置已淘汰，不能外推为所有局部恢复无效；192步独立对照尚在运行。来源为同专题 `sequential_no_rotation_n64_s64/acceptance.json`、`run/recovery.json`。

同一无旋转/INT8底座上的teacher-input block16联合decoder与码字优化，128step/LR/码字round/公共64留出都固定时，训练文档从64增至512，native留出终点从8.311694降至0.342414（共同初值11.377072），训练终点分别0.195405和0.210809。最终翻码反而从8,457,934降至7,220,977，冻结字节、保存重载及位宽均通过；扩大数据明显缩小了这次局部实验的训练/留出差距。它支持将512用于下一全36块候选，但仍不能替代完整八任务验证，也不证明其他层或语料的相同收益。该公共留出已用于样本量选择，必须记录为校准dev，不能继续称未参与选择的独立确认。来源为同专题 `validation_joint_block16_n64_s128` 与 `validation_joint_block16_n512_s128`。

2026-10-01全模型结果补齐：固定该BF16源及旧部署kernel，252投影纯码字恢复有248个native训练MSE改善、239个校准留出改善，却使完整八任务由60.8495%降至58.1046%，且252个权重MSE均增加。192step顺序decoder恢复有36/36训练、35/36留出改善，八任务53.8622%，同样低于源。更长局部预算或大部分局部留出改善都不足以说明模型任务收益；这两份配置不再推进。同期另发现旧fused kernel失配，单凭这些指标不能把掉点全部归因kernel，修后模型必须重建同核基线；本轮最高底座上的全模型decoder/编码KD与局部目标是不同实验。完整SHA核对、按类摘要和原始八任务见同一Qwen3专题的两个终态记录。

后续512文档、全36个teacher-input块的decoder+码字联合恢复也给出了完整反例：36/36块native训练和校准dev误差下降，等块平均after/before分别0.3777/0.5583，504个decoder stage都有更新，499/504编码bank最终不同，共418,893,605个最终翻码；但修复后的同一部署核上，八任务由原源60.9186748%降至47.7827673%，八项全部下降。成品冻结状态、2919tensor重载和2.453873344bpw账本通过。这排除了用局部dev改善或“翻码确实发生”作为该全模型配方质量依据；尚不能单独确定teacher-input偏移、校准分布或目标不匹配各占多少。该具体配置已淘汰，模型输出蒸馏是另一个待验证假设；原始八项和局部摘要见同专题 `joint_no_rotation_n512_s128/eval_fixed_decoder/`、`local_metrics_summary.json`。

相同修复部署核下，block32/INT8保护/H128底座的模型级输出蒸馏已有首批正结果：固定五源SFT数据、prompt0.3、mass-KL top100、B4/max1024、400步，decoder LR1e-5使八任务61.3301412%→64.0511955%；只增加1%活动位、decoder_sensitivity代理坐标、Adam bit LR4e-5/round128为64.5023836%。两者全部八项超过同源基线，实际2.456988791bpw、无外置LoRA。编码臂比decoder高0.45119个百分点，其中RTE多对9题贡献约90%，其余四项略降，故只支持该成品的完整均分更高，尚不证明编码学习的稳定普遍收益。编码最终XOR201,756位，不能与按轮重置的翻转事件数混用。这与局部MSE失败不矛盾，数据、目标及优化范围均不同；69%仍未达到，后续步数与对照继续。来源为同专题 `e2e_decoder_block32_lr1e5/step_0400/`、`e2e_bits_block32_r128_lr4e5/step_0400/` 的原始全评及审计。

同轮400步对照也限制了“提高更新强度”的外推：decoder LR提高3倍后完整八项为61.0343%，MMLU降至50.5484%；bit LR提高4倍、其余相同，最终翻码增至58,885,257位，却只有62.3535%，主要损失来自BoolQ/RTE，MMLU与低bit LR几乎相同。这是实际全评与冻结审计通过后的差异，不是依据翻码量推测质量；只否定这些中期点优于低LR成品，尚不能替代后续步数的终态判断。原始证据在同专题另两组 `step_0400/`。

2026-10-02，同源、有效B4、decoder1e-5/bit4e-5/round128的400步成品已补齐四组完整strict全评：decoder-only/1%/5%/100%分别64.0511955%/64.5023836%/63.9406157%/64.9235275%，实际2.456988791bpw、rank0，实际MMLU64/seven32和完整协议一致。100%比decoder-only/1%/5%分别高0.872332/0.421144/0.982912个百分点，但覆盖比例与准确率不是单调关系；相对decoder六项提高、一项持平、BoolQ下降，相对1%仍有BoolQ/RTE下降。5%和100%最终XOR分别792,930和15,749,205位且冻结审计通过，前400步对应token统计窗口相同；100%另有按层四卡执行差异，不能宣称所有执行条件完全相同。该结果支持100%在本保存点的观测领先，尚不证明部分覆盖导致优化不稳定、全覆盖解决不稳定、所有步数均领先或达到69%。此前5%/1%2000步结果不能替代同预算100%对照；完整指标、配置和信号中断后的同成品补评证据仍见上述专题。

100%码位的800步全量结果随后为62.4577585%，低于同800步decoder-only/1%/5%的65.5210231%/64.9002728%/65.6476744%；相对自身400步下降2.465769个百分点。主要BoolQ从81.2844%降至67.3394%、RTE下降4.693141个百分点，而MMLU仍提高0.683663个百分点。实际批量、完整协议、2.456988791bpw、冻结与3423张量严格重载均核验通过；最终XOR35,939,546位，其中第二残差stage（零起始索引1）占35,900,526，不能将全覆盖当作均匀翻码或把翻码量当收益。结构转换同路径误差0，训练到部署诊断误差也未超过400步，未见足以把退化归于保存损坏的证据。其前/后400步记录loss均值0.44162/0.36855，梯度范数记录也下降；恢复后40个token统计窗口与decoder对照一致，但不等于逐样本身份一致，日志过滤亦不证明每一步全部中间值有限。该点否定“400步领先可外推所有预算”与“全覆盖已解决质量问题”，尚未识别根因，也不证明部分覆盖导致不稳定；按层四卡执行差异仍需保留，1200及后续点继续。原始来源为同Qwen3专题 `e2e_bits_block32_a100_mp4_r128_lr4e5/step_0800/`。

## 下次怎么做

- 替换损失前，测量新旧重构项、梯度及辅助项的相对尺度；将尺度对齐作为独立变量，保持初始化、预算与评测题目一致。
- 分组目标验证 H=I 退化为 MSE、对角 H 退化为 AMSE，并比较数值和梯度；测试通过只说明实现语义。
- 完整 Linear 输出目标应先累加各输入块贡献再取平方，保留组间交叉项。分组二次型没有这些交叉项，不能视为同一目标。[完整输出目标记录](../records/experiments/linear_output/EXPERIMENT_SUMMARY.md)
- 全局 BSQ entropy 等辅助项不能因显存分块就改成块均值的平均。teacher-input 与 student-input/teacher-target 也应作为不同实验。
- 使用相同题目配对评估；题目 bootstrap 不覆盖训练随机性，多个训练种子也不是新增独立题目。
- 比较校准量时统一构造最大训练前缀和其后的公共留出，再按文档组/token去重；扩大训练集后，已进入训练前缀的旧留出不能继续当独立确认。保留训练、留出、权重误差和优化轨迹，最终仍以完整八任务验证。

## 边界

局部3层、小题集的失败不能外推为全部输出感知优化无效；新增完整MLP候选也尚无超过纯CAT最佳的尺度校准收益证据。逐 Linear 实验的部分模型不能当作全模型2-bit成绩。
