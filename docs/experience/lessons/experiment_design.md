# 对照设计：先对齐条件，再解释增益

## 问题与证据

- 残差 LoRA 对照曾误选 40 步、limit16 的 smoke_B，其损失、dropout 和预热也不同；后改为用户指定的普通 LoRA 基线。有效八任务对照在 step2000 仅 +0.1152 个百分点，不能据此宣布达到 69+ 或稳定显著提升。[记录](../records/docs/exp_results/residual_lora_ab_20260923.md)
- 独立 down_proj 的蒸馏前基线为 67.93%，全类压缩基线为 54.51%，两者不是同一模型状态。早期前缀/独立类别比较还混有 rank、steps、训练对象和数据比例差异，不能把全部分差归因于一个开关。[down_proj](../records/docs/down_proj_recovery_experiments.md)、[前缀对照](../records/docs/cat_distill_prefix_vs_independent.md)

## 下次怎么做

1. 实验前固定初始 checkpoint/版本、压缩与训练范围、数据与 token 预算、seed、实际 LR 序列、精度、任务集、shot、limit、metric 和聚合方式；只改变研究变量。
2. 复用口径匹配的历史基线，不用冒烟替代正式基线。若历史运行存在恢复、不同种子或非确定性，写清局限。
3. 修改 max_steps 时检查实际 LR，而非只看参数名。本组用2001步取得step2000评测，同时保留原5000步余弦前段；这是特定回调行为，不是所有训练都该用2001步。
4. 新增 hidden loss 后分量分别记录，总 loss 不再和旧总 loss 直接比较。
5. 先报告最终部署状态/全压状态的指标，再解释中间单类指标。分数百分比与差值百分点分别标注。
6. 方案里列明已查经验、避免重犯的方法和不一致条件；再次尝试失败路线要有新变量或待检验机制。

## 边界

上述记录是单次或有限配置实验。独立类别的历史失败提供风险信号，不证明该方法在所有联合恢复策略下必然失败；统计显著性也不能由一次小幅均分上涨替代。本次整理没有重跑基线或验证当前代码的回调行为。


## 短程小差距、代理排序与完整预算（2026-09-24）

**本配置实测支持。** 0910 rank8搜索中，单卡B4的LR1e-4/3e-4在相同200步下均分差约0.11pp，方向主要由277题RTE的5题差驱动，其余七任务平均方向相反；B32的400步LR差约0.07pp。两种协议还混有预热、步数和样本曝光差异，不能把均分符号不同宣布为已证实的batch×LR排序反转，也不能由E200→400小幅下降推断长程上限。[原始结果、比较条件及后续预算](../records/e2e_0910/2026-09-24_rank8_search.md)

**动作与边界。** 主指标仍用原八任务完整均分，分项只解释差异来源，不能为得到更好结论临时删RTE或改权重。差距小时先延长匹配候选到共同预算，再决定晋级；小batch、短程选择仍须校准向正式条件的迁移。比较成本使用实际更新日志与完整保存/评估/恢复耗时，不能仅看训练秒/步或HF按配置max_steps推算的summary吞吐。本组全量评估已占单卡200步阶段主要时间；精确续训的评估间隔仍遵守原契约，不能把更改评估频率当成无语义变化的加速。

C在同B32/400步下比A稍低而含评估总时间约3.1倍，因此可为提高搜索效率暂停该具体配置预算；这个决定不证明decoder所有配置无效或已达到上限。新假设H（mass K100）和I（partial K1000）各自以E（partial K100）为对照，二者直接互比同时改变两个因素，不能用于单独断言K的效果。


## 自适应搜索的覆盖饥饿、停止门槛与冠军确认（2026-09-30）

**实测与代码共同支持。** 0910固定数据搜索完成96个新候选及6个确认，最高67.663915%。固定候选生成顺序反复围绕新中心更新，前部的alpha/dropout/norm/head新组合消耗候选额度，列在后面的mass/CE/weight_decay实际未被执行。候选池包含某方向不等于已搜索该方向；应预留每类最小覆盖额度，再做局部自适应精调。[完整覆盖计数与原始证据](../records/e2e_0910/2026-09-24_seven_day_search.md)

**停止和确认边界。** 末16组改善0.07995557个百分点，因低于0.08的严格阈值而未扩展，七天预算还剩约66小时。这是资源规则触发，不是上限证据；如此小的门槛差应结合评估不确定性、剩余时间及未覆盖方向，避免假精确停止。下一轮调整规则必须事先写入实验协议，不能事后改口径来美化此次结果。

**冠军确认应对应同一配置。** 本次seed1只验证选定中心的B4配方，新冠军来自B16，不能把前者当作后者的种子复验；应为最终冠军留出同batch/调度的确认预算。B4长程与B16比较使用共同样本曝光点，两组公共点均差仅+0.1601/+0.0978个百分点，不能由单个峰值推出batch始终更优。保留中间最佳模型及原始指标，终点模型不能替代中间冠军。本次未证明67.66是LoRA能力上限。

## 0920顺序搜索的收益与中途最优（2026-10-01）

**单seed搜索已完成，训练与交付指标分别确认。** 北京时间2026-10-01 02:20:35，固定0920初始ckpt、rank8、数据及`kd_top_partial`类型的六个坐标全部完成，共15组配置，12组到5000步、3组到2500步。独立调整head LR、norm LR与dropout后，同为step2500的训练内均分较先行LR1e-4组提高0.1584个百分点；再将pre-MLP权重从.01置0，达到68.009998%，累计+0.2844个百分点。各坐标继承此前优胜配方，不能据此宣称每个参数都是独立的全局最优。[配置、原始指标与结果](../records/e2e_0920/2026-09-24_rank8_search.md)

**先看任务构成，再解释均分。** 在匹配初始模型、数据和2500步预算的训练内对照中，最佳配方较先行LR1e-4组八任务6升2降，RTE对均分贡献+0.2256个百分点，占累计收益大部；不能把单seed小幅均分改善称为全面或稳定提升。

**保存中途最佳，再以交付模型复评。** 所有配置已观测到的训练内峰值均在2500，包括12组跑满5000步的候选；先行三组直接1000→5000也在该点评测最高，回落原因未独立定位，不直接归因为暂停恢复或过拟合。排名前三的2500步快照经独立strict重载、全量八任务0-shot复评，最高68.024489%，最终仅保留该交付模型。训练内峰值不能替代导出重载成绩；本次未达69不证明该初始模型或rank8的能力上限。
