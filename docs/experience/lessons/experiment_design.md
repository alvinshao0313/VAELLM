## 下次怎么做

1. 实验前固定初始 checkpoint/版本、压缩与训练范围、数据与 token 预算、seed、实际 LR 序列、精度、任务集、shot、limit、metric 和聚合方式；只改变研究变量。
2. 复用口径匹配的历史基线，不用冒烟替代正式基线。若历史运行存在恢复、不同种子或非确定性，写清局限。
3. 修改 max_steps 时检查实际 LR，而非只看参数名。本组用2001步取得step2000评测，同时保留原5000步余弦前段；这是特定回调行为，不是所有训练都该用2001步。
4. 新增 hidden loss 后分量分别记录，总 loss 不再和旧总 loss 直接比较。
5. 先报告最终部署状态/全压状态的指标，再解释中间单类指标。分数百分比与差值百分点分别标注。
6. 方案里列明已查经验、避免重犯的方法和不一致条件；再次尝试失败路线要有新变量或待检验机制。

需要解释任务分数变化时，确认逐题结果实际落盘，不能只确认评测器开启了 `log_samples`。2026-10-10实查本项目snapshot的LM-Eval已在内存生成samples，但serializer只保留汇总，导致七项无法区分修回/损坏，也缺少实际hybrid教师的七项读出；净正确数相同不等于预测不变，BF16不能替代不同的混合教师。后续隔离入口保存同次原始samples、任务/题目/过滤器身份及输入hash，不新增推理；先前1824条真实MMLU样本CPU往返只验证已有路径。同日D1Q0完整评测首次实际保存全部64叶/24742条，逐文件hash/行数/身份及逐题acc/acc_norm重算均与原指标一致，补齐七项实际写出验证。原结果无法由保存补丁追溯恢复，不仅为补日志重跑旧评测。见[证据缺口及独立保存扩展](../records/w25_transfer/2026-10-04_mmlu65_llama31.md#10月10日六组答案蒸馏完整结果与保护通道可学习原型)。

## 先核任务协议，再解释不同能力的退化（2026-10-09）

Qwen BF16/a0e5完整LongBench审计逐条核对4750份输入、生成参数与实际生效值，官方21项重评分复现原结果。当前32768是输入与输出总窗口，15项为非思考chat、6项按官方使用原始completion；最终token中删是明确记录的模型适配，不能称为32768纯输入或与上游截断逐字相同。94条输入截断不涉及检索、Qasper及多文档QA；不能用窗口差异解释这些任务的主要下降。输出触上限也不等于官方评分一定截坏，需先核首行/代码行处理及逐任务实际生成。

同一端点的摘要均分仅降约.65，单/多文档QA分别降约8.50/9.82、代码降约10.86；LCC在不超过2K输入时已退步，其它任务长度分层也不统一单调。因此按任务性质选择读出与数据，不能把所有退化都当作长attention问题，或用一个QA子集替代完整LB。MMLU改变0/5-shot时，两侧须共享示例来源、模板与批量并重评；本次同shot从B64改B16，BF16/压缩各变化3题，说明小差异不能直接归于shot。同B16完整14042题中，5-shot使BF16增加284题、a0e5增加216题，两侧准确率均提高但差扩大68题；九项差0-shot为1.76547、5-shot为1.81928。较高的压缩绝对分不等于较小的压缩损失，这也不证明5-shot在其它模型/端点同样较差。比较所有合理设定、明确观察后选择与原协议的差别，不交叉减不同设置的基线。[审计及配对记录](../records/w25_transfer/2026-10-04_mmlu65_llama31.md#10月9日评测设置与任务特性核查)；完整21项仍等权作为九项中的一项，分类和长度分层仅诊断。

输入条件对照也须看分组和可实现性。固定32篇新Qasper train文档，BF16/a0e5全原文F1为41.68/30.04，直接提供人类证据后44.81/44.87；两边模型冻结。总体gap缩小11.70pp，但预先固定的两个半集分别只缩小23.02/.375pp，不能把总体均值称为稳定恢复。人类证据同时改变长度、干扰和位置，只支持继续测试无标签的证据选择，不证明attention根因或可部署收益；相同数量未标注段落也不保证无答案，删掉必要信息后的合理拒答可能得低参考F1。[同一记录中的证据上下文配对](../records/w25_transfer/2026-10-04_mmlu65_llama31.md#10月9日评测设置与任务特性核查)。

## 检索错误要沿实际生成位置定位（2026-10-08）

**证据。** a0e5的8例结构采样中，唯一失败EN97正确段18却输出1。完整原生自由生成、独立KV对照下，仅替换L18 QK仍答1，L0 MLP答13，L24 V/O答18；差异发生在实际生成`Paragraph 1`后的第二数字/EOS竞争，其余7例四臂token相同。固定prompt尾或首数字观测会遗漏这个失败。BF16模块替换仅是条件干预，不能据此断言OV独立解释检索下降；本次也没有测干预后的attention。

**动作与边界。** 用真实cached生成的prefix及当前logits定位，不强制答案、不加EOS规则。教师在学生prefix下的偏好不等于教师自由生成答案。采样attention的A×V重构误差与完整prefill/cached生成差异分别报告；近乎平局的数字/EOS可因BF16差异改变argmax。这样的8例只用于机制诊断，不用于选训练层、损失或完整LongBench结论。见[原始生成与精度核对记录](../records/w25_transfer/2026-10-04_mmlu65_llama31.md#10月8日晚选码规则读出诊断及配对完整评测)。

2026-10-09在a0e5的L18完整同层十臂对照中，上述边界得到更直接的条件证据。固定221题原生MMLU、16篇train证据QA，QK替换把本层共同输入map KL降到0，MMLU却修2坏6；VO/down在保留本层QK和相同输入的条件下，修复了语料规模误判与两组实验混淆，联合QK又可撤销其中修复。单层七投影对MMLU只净+1，教师输入+七投影净+19，正确数交互cal/confirm各+5；这不证明局部优化或直接hidden对齐能学到相同收益。动作是同时比较局部投影、上游输入与两者组合，保留修回/损坏和实际生成；不能凭map误差、单臂收益或深层hidden替换幅度直接选训练模块。更深的teacher输入替换也包含更多上游层，不能冒充该深层更敏感。QA文档配对区间仍跨0、B1与原B64各有一题近并列变化，均已单列；这是机制数据与超预算BF16干预，不是正式任务收益。[完整十臂、实际答案及不确定性](../records/w25_transfer/2026-10-04_mmlu65_llama31.md#同层配对干预与后续机制数据10月9日)。

同日预先确定的L6/L30补齐后，三个深度的同轮S原生答题和生成保持一致。L6/L18/L30教师输入+七投影对MMLU分别净−7/+19/+19题，但与单独教师输入的交互不同：L18的联合额外净+10，L30为0；L30局部VO/down也未复现L18的QA增益。这限制了“统一全层对齐”或“选一个普遍敏感类别”的推断：深度、当前投影和上游状态有条件关系，尚不能用有限干预决定可学习算法。后续目标对照必须明确保持哪个学生中间量，例如 `down_T(product_S)` 与 `MLP_T(xS)` 并不等价；旧后者的拟合负例不能自动否定前者，也不能因前者BF16干预有效就保证低比特decoder拟合成功。新目标只进入隔离短测，末态仍看未训练文档的真实答题/生成及修回/损坏，而非局部MSE。来源同上。

二元正确率的2×2交互也不能直接当作表征非线性协同。L18的连续归一margin/条件NLL交互区间均跨0；四道单独干预未修好而联合修好的题，原始四选项logits的线性相加已经足以跨过正确阈值。加和169题与真实联合175题仍不同，应分别报告阈值效应和剩余不加性，不混用它们。四臂raw/native argmax逐题一致已核对，未修改正式打分。来源仍为同一report及上述记录。

既有三层的完整前缀MLP几何量也不能直接当任务敏感度。教师正确175题中，以较大MLP相对L2预测学生失误31题，L6/L18/L30 AUROC为.442876/.511873/.485439；SiLU真实非线性余项的对应值.335797/.609095/.608423，固定方向且全部报告，未作显著性或多重校正。非线性余项存在不等于已定位答题损失，输出方向与关键位置仍待实际干预连接。三个层各237篇down映射误差与上游product误差传播的完整向量交叉项全正，也不支持凭直觉归结为全段误差抵消。

同源L18 VO-conditional固定500步进一步暴露“可拟合”与“可修复”的区别：237/237文档的条件/完整输出目标误差均下降，未训练MMLU/QA条件误差下降约19%/21%，但原生答题156→155、QA F1 20.810→19.978，密集替换的两处内容修复未出现；独立BF16参数重载后全部237读出精确复现。这不是仅看训练loss，也不能简单归为留出拟合过拟合或导出丢失。下一步须分开检验读出位置、更新方向/幅度与目标语义；在这些对照完成前，不凭全prefix误差宣称能力增益，也不凭一个短程端点否定所有局部恢复。来源同一记录的 `qwen_causal_output_fit/vo_conditional_s500`。随后两目标500步配对及原生几何完成：两臂×两目标×三位置的237篇误差都下降，QA条件臂在prompt末query的剩余误差约.817，但两臂QA生成完全相同、MMLU逐题对错相同。因此不能再将这组失败解释成“query完全没有改善”。完整训练对QA条件目标的prompt距离反而16/16更好，说明连关键位置的欧氏距离排序也不能替代答案。沿现有输出更新方向的最优统一标量约1.034、几何收益极小，仅限制固定向量缩放假设，不证明加步数无用、参数容量不足或关键方向已定位。后续若做密集修复剂量响应，固定全部样本/系数并保留每系数自己的自由生成prefix/KV；TF缓存目标不得用于伪造自由生成。见同记录 `query_geometry_vo_pair01`。

同配置down的条件/完整目标配对随后也完成：固定500步、两目标在全部237篇局部误差均下降，MMLU均156/221（各修1坏1），QA却由20.810降至17.873/18.278，训练及确认文档均无QA改善。因而“保留学生上游的条件目标”本身没有解决这一可拟合与可修复差异；不能凭它扩大到全层，也不能据此判定容量或步数不足。先用固定BF16修复强度观察答案响应，可帮助决定是否值得追求更大修复幅度或不同更新方向，但强度不等于训练步数/参数可达性；该诊断也不能替代完整九项验收。来源同记录 `qwen_causal_output_fit/down_conditional_s500` 与 `down_full_s500`，原生基线精确重放、冻结/部署及CPU逐题评分已核。

同源L18 down、相同40cal和固定32更新的目标配对进一步区分了方向：局部NMSE由.050108降至.045963时QA16略降；经过冻结学生下游的条件答案KL则下降84.07%，QA16提高8.52pp，尽管40/40篇局部NMSE均变差、均值增加19.89%。两臂只更新原六decoder，输入/目标/冻结状态及原生重载已核。这支持该配对中局部欧氏误差的排序不能代替答案恢复，不证明所有层应统一用答案KL。另32篇未训练完整论文上，NMSE端点32个生成全文均不变，KL只+1.058pp、2篇改善3篇退化且确认半集无增分；小开发集合上的内容修复尚未稳定推广。后续同新32的原生BF16 down替换本身也仅+1.335pp，而完整BF16差11.636pp；均值接近KL但修复/损坏题不相同。故先分开检验条件目标本身的可修复性与拟合预算，不直接把弱泛化归为训练太短，也不把该条件donor当作参数容量上界。不同时改变数据、teacher和步数，不以训练KL降低声称泛化。见[同一主题中的固定32及独立新32配对](../records/w25_transfer/2026-10-04_mmlu65_llama31.md#10月9日评测设置与任务特性核查)。

同日扩到全部36层的attention×MLP配对后，单MLP恢复对M221净+13题、QA32净+8.21pp，明显大于同集合L18单down；all7的原生M逐题及QA生成精确复现BF16。attention单臂知识分数反降，且两单臂raw-logit相加仅160题、实际联合175题，说明在这个端点不能把各类别看成独立可加收益。该证据足以把下一步转向跨层MLP补偿，无须等到分清所有微观机制；但HF替换同时撤销既有恢复、超出位宽预算，仍需验证原低比特decoder可学性和未训练文档效果。保留QA分区异质性、内容/长度引起的F1变化，以及小样本区间；不能以诊断收益替代完整九项。见[全层模块配对与补偿方向](../records/w25_transfer/2026-10-04_mmlu65_llama31.md#10月9日全层模块交互诊断与qwen优先)。

另一方面，直接把QK恢复为原BF16与主动学习QK补偿学生输入偏移不同：前者匹配共同输入下教师映射，后者可以尝试匹配自然教师输入下的map，当前替换并未检验后者。教师/已恢复学生权重差还包含历史恢复更新，不能把它全部称为纯量化误差。证据和条件边界见同一记录的 `mlp_error_geometry.json` 及原生投影干预。

2026-10-10完整九项给出新的方向边界：同a0e5、原40条、MLP decoder32步的三组低LR（hybrid gold、full7 gold、full7 OPD）均同时提高MMLU与LongBench，但其他七项退化，使九项全部低于原模型。不能由开发QA提升或两目标训练loss下降推断全能力恢复，也不能把综合退化笼统称为MMLU/长文冲突。应分开计算相对BF16的原始缺口和相对当前压缩模型的新增损失，再用配对数据/参数范围对照检验覆盖不足；这个解释尚未证实，不等于自动停止预算对照。同组a0e5的七项合计已高BF16，而MMLU/LB仍是主要缺口；即使假设完全消除最佳低LR恢复的七项损失，九项仍差目标约.860分。故避免遗忘有价值，但不能据此认为回放足以达标，也不能默认BF16教师在所有任务都是保留现有优势的目标。这一算术分解只约束当前端点的决策，不是可达性能上界。 同一donor的四个深度保留臂全量九项也均低于源，最接近者仍低约.115分；它们只检验事后保留更新，不能当作分组独立训练或通用层敏感性排序，也不支持仅因某组最好就继续拼接。见[六组完整结果](../records/w25_transfer/2026-10-04_mmlu65_llama31.md#10月10日六组答案蒸馏完整结果与保护通道可学习原型)。

增加样本数时核查实际覆盖的类别及选择规则，不能只看总条数。2026-10-10原32道MMLU来自过滤后111条的hash前32，覆盖26科；扩到128题沿用原学科槽，仍是26科。完整57科中，扩池相对原控制的＋9题来自已覆盖科＋10/其余31科−1，但其余科相对源仍净增21题；未覆盖科的BF16差距也没有更大。因此支持隔离检验更广学科覆盖，不足以认定覆盖不足是主因。canonical按题量微平均略升、等科宏平均略降，两者用途须分开；保持正式指标，诊断全报而不按test挑科。初始228题/57科在排除test重叠后实际221题/56科，calibration111题也仅56科，不能从初始配置推断过滤后的覆盖。完整来源、可用候选及条件式同预算对照仍见同一记录。

## 边界

上述记录是单次或有限配置实验。独立类别的历史失败提供风险信号，不证明该方法在所有联合恢复策略下必然失败；统计显著性也不能由一次小幅均分上涨替代。本次整理没有重跑基线或验证当前代码的回调行为。
