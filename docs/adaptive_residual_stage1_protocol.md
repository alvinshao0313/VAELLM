# 自适应残差阶数训练：第一阶段4bit基线流程规范

2026-11-08建立。**目的已确认：给定另一个受支持的原始模型，按统一规则完成模型适配、压缩设置选择、压缩与恢复、完整验收，交付适合后续自适应残差阶数训练的良好4bit基线。** 固定的是生成、比较和验收方法，各模型可以得到不同参数；不把Qwen某次成功的checkpoint或参数组合当成通用算法。

**初始化搜索规则已确认，执行适配与恢复细则待完成。** 用户2026-11-08明确：第一阶段沿用SC-CAT的初始化搜索，**取消INT8高精度保护，全部目标投影权重进入四阶BSQ，每阶K=D**；得到良好基线后，第二阶段才学习各向量的残差阶数。固定候选表、逐项选优与完整验收保留，不再逐项重复确认共同搜索规则。总GPUh、实际执行适配及恢复安排仍需落实；本次没有启动实验。历史Qwen达标候选带INT8保护，不能作为新无保护规范已经通过的证据。

唯一运行计划见[当前计划](experience/records/w25_transfer/current_plan.md)。共同搜索方法引用[SC-CAT标准](sc_cat_protocol.md#sequential-search)，执行与记录方法引用[SC-CAT执行规范](sc_cat_execution.md)；本文件只明确S4表示、取消保护及阶段目标等差异。SC-CAT的S2、约2.5bit类别码率分配和≤2.6bit验收不进入本阶段；门控、渐进降阶和最终极低位宽训练另行设计。

## 1. 输入、输出与阶段完成

输入包括原始BF16模型与tokenizer、原始开源训练数据、对应BF16教师、评测协议、已确认的候选范围和资源预算。不得要求用户先提供某个旧实验的中间压缩模型，才能执行本流程。

最终交付包括：一份全部目标投影无INT8保护的原生全四阶压缩模型、一份可从原始BF16生成它的完整配方、同一模型的九项原始指标与预测、费用账本、来源绑定和阶段报告。若预算内未达标，交付明确标记的研究结果、差距和失败边界；不能降低目标或以相对某个旧压缩模型改善代替验收。

分别报告三个状态：

| 状态 | 完成依据 |
| --- | --- |
| 候选数值达标 | 同一个无INT8保护的全S4模型同时满足费用与完整九项质量条件 |
| 第一阶段流程可复现 | 冻结生成配方后，以原始BF16为根重放受影响整链并完成同样验收 |
| 跨模型方法已验证 | 另一模型按相同规则重新生成、选择和验收成功；不能仅加载Qwen成品作证明 |

前两项闭合后，阶段产物可反复复用为门控研究的统一起点，不必重复生成稳定前驱。阶段目标、数据、表示或关键上游配方改变时，重做受影响部分；局部恢复收益不能拼成整链结论。

## 2. 固定表示与质量契约

- 全部目标投影的**所有权重向量**均保留四阶残差BSQ，每阶`K=D`，主码率为`Σ(K_s/D)=4bit`。K指BSQ二进制码维数，D指权重向量维度；本阶段不搜索残差阶数、分配不同主码率或提前mask尾阶。
- **INT8保护数量固定为0。** 不抽出保护通道，不建立保护整数／scale恢复分支；已带保护的旧checkpoint不能直接充当本规范基线，也不能只删除保护字段而不重新拟合完整权重。取消的是目标投影中的高精度保护，不改变decoder、归一化统计和计算的原生精度；embedding/head/norm仍按既有目标范围处理。
- decoder、归一化统计、旋转、padding等按实际存储计费；同时报告logical、packed、权重tensor与完整部署目录，embedding/head/norm等账本外存储另报。主码4bit不等于含开销总位宽恰好4bit。4.094031292459239bpw是历史带保护Qwen实例的实测值，新表示必须重算。
- 完整费用预算在候选生成前声明；不能通过浮点补偿、额外阶数或重新增加保护绕过本规格。完整开销上限的通用数值尚未确认，不自行新增4.1或4.2bpw门槛。
- 相对**本模型自身BF16**，同协议九项未舍入均值下降严格小于0.4个百分点；MMLU准确率下降不超过1个百分点。LongBench完整21任务的task macro作为九项中的一项，不按21项展开权重。

令本模型BF16九项均值为`S_BF16`，MMLU正确数为`n_BF16`、完整题数为`N_M`：

`S_S4 > S_BF16 - 0.4`，且`n_S4 ≥ ceil(n_BF16 - 0.01 × N_M)`。

各均值使用0–100分单位。当前MMLU协议为57学科／14042题，八项共64叶／24742条，LongBench为21任务／4750条；新模型重新核协议与完整覆盖，不能继承Qwen的10251题正确数或67.64714492分绝对门槛。

## 3. 换模型时固定什么、重算什么

| 类型 | 内容 |
| --- | --- |
| 流程固定 | 从原始BF16生成、全部目标权重S4且K=D、无INT8保护、train-only训练、统一比较、完整验收、来源与费用可追溯 |
| 模型适配 | 模块名及类别映射、层数、投影shape、GQA／fused或shared结构、原生attention／RoPE／上下文政策 |
| 按模型重算 | 完整权重的向量布局与方向、分组、实际账本、正式batch／并行映射、峰值输入和资源 |
| 按模型重建 | 原生token化、选项支持集、因果位置、教师概率／词表KL缓存、模型自身BF16完整评测 |
| 按本模型实验选择 | 压缩超参、恢复插入点／范围／预算／LR、是否合并及合并比例 |
| 仅为历史Qwen实例 | 36层／252投影、gate D64、INT8保护64／down256及其QAT、skip-up、具体恢复步数、0.75合并比例 |

不通过模型名称硬编码Q/K、MLP或某层更敏感。遇到未支持的fused投影、共享参数、布局或上下文要求，先明确并补适配；不能静默跳过目标投影、改变评测长度或换算法。

合法性检查针对**未剔除任何保护通道的完整矩阵**、实际转置／旋转与D进行。没有保护数量取整或保护比例搜索；遇到不支持的shape／D要记录未覆盖原因，不能临时抽出高精度通道来满足对齐。旧带保护布局、bank和局部质量结果不替代新无保护候选。

## 4. 数据与教师准备

校准、恢复和诊断池分开记录原始来源、revision、license、split、case身份与顺序。训练只用开源train／auxiliary_train；不按正式测试逐题表现挑训练样本。

同模型、同tokenizer、同prompt与教师数值路径时可只读复用已验证缓存。换模型可复用原始训练文本身份，**重新token化并用新模型自身BF16教师计算目标**；不同词表、选项token或因果位置的缓存不能互换。知识域与QA域的混合权重、teacher/gold比例分别记录，不能重复混gold。

恢复初始参考为知识选项分布`m=0.5t+0.5gold`及`KL(m||p)`、QA gold-prefix全词表教师KL，知识与QA域权重各0.5。它是已测起点，不是跨模型最优结论；调整目标、数据来源、数据比例和参数范围分别比较，不同时改动后解释为单因素收益。

每条候选保存真实消费组、唯一身份数、重复次数、非padding输入token和有效监督位置。64步只训练某数据包前半时，不能声称已经训练全部知识池；观察面板中未消费后半与独立heldout分开命名。

## 5. 从初始化到恢复的完整流程

| 环节 | 输入与动作 | 输出／判断 |
| --- | --- | --- |
| 模型准备 | 真实inventory、数据与教师、同模型BF16九项；复用适用已有证据 | 模型／数据／评测与资源契约 |
| 四阶表示设置选择 | 沿SC-CAT共同搜索表，在共同BF16上比较无保护S4候选；每阶K=D | 本模型各类别候选配置及完整比较依据 |
| 正式逐类构建 | 从原始BF16按冻结类别顺序，实际拟合并安装该类四阶；未来类别保持本次BF16 | 当前类压缩后、恢复前的真实节点 |
| 类别恢复 | 比较已声明的恢复插入点／范围／预算；只允许当前规则选择的真实终态进入下一类 | 压缩损失与恢复增益分开记录的累计链 |
| 全S4恢复 | 从本轮全部类别压完、末段恢复尚未开始的节点出发，比较固定配方 | 完整S4候选、连续训练状态与原生端点 |
| 可选model merge | 仅对满足来源及冻结一致性的端点按预先声明比例合并，并独立评测 | 无需增加部署位宽的独立候选 |
| 定稿与重放 | 固定完整配方，从原始BF16重放受影响整链 | 同模型九项、账本与复现验收 |
| 第二阶段交接 | 交付通过验收、所有目标权重均有四阶表示的bank及来源；后续训练建立新阶段状态 | 可复用的门控训练初始化；每向量降阶由第二阶段学习 |

原生单类可从共同BF16离线拟合，用于设置比较；实际累计链的前驱和恢复会影响后继，最终采用者仍须在自身live前驱上按配方构建。不得把不同父或不同轨迹的各类最高分模型拼成整链收益。

类别内部按真实部署累计贡献计算下一阶残差，依次拟合四阶；保留bias、融合统计、旋转与原生累加语义，无保护回填路径。后阶不能改掉已冻结前阶。拟合按实际模块分组；不把Qwen的M36或固定batch强加给不同层数的模型，也不为并行随意改变BSQ熵归约。

## 6. 沿用SC-CAT的初始化搜索

**用户已确认复用SC-CAT的初始化搜索，取消高精度保护。** 按[共同候选表](sc_cat_protocol.md#sequential-search)、[逐项选优](sc_cat_protocol.md#5-逐参数搜索统一选优与结束条件)、[逐层转置](sc_cat_protocol.md#layerwise-transpose)及[离线前两名](sc_cat_protocol.md#offline-top2)执行；下表只列S4展开结果及适配差异。每个新模型均完成该固定表，不因参考起点已达标而跳过搜索。执行批次绑定所用规范版本，后续规范修订不自动改变在途任务。

同一轮只改声明的变量，其余父模型、样本／顺序、教师、seed、训练日程和评测保持；各候选独立初始化。选择本轮完整配置进入下一轮，不能从不同基底各摘一个最优参数。相同配置且来源／协议／预算一致时复用结果。

| 搜索部分 | 需要在规范中固定的规则 | 本轮证据与未决部分 |
| --- | --- | --- |
| 转置／旋转／D | 沿SC-CAT顺序及候选；改变D时每阶仍K=D、S始终为4 | 无保护比例轮、无类别主码率粗查／联合分配；不继承S2分数或2.6bit cap |
| encoder／decoder／拟合优化 | 沿SC-CAT结构起点、宽度／优化器／倍率候选；每阶完整10K，候选各fresh拟合 | 搜索方法复用，真实S4实现适配与费用另核，不把S2证据当S4质量验证 |
| 类别恢复 | 是否恢复、当前或累计prefix decoder、预算节点与LR、完整选优准则 | 不固定skip-up；Qwen负例不证明其他模型up也应跳过 |
| 全S4参数范围 | decoder及必要子范围的恢复安排另定 | 新模型没有保护整数／scale可训练组；旧保护分支只能作历史证据 |
| 目标与数据 | 初始目标／数据配方、允许的单变量候选及接入次序 | 不把0.5、Web/Med或双向KL写成已证通用最优 |
| 合并 | 启用条件、端点生成规则、统一比例候选、有限选优与验证 | Qwen三比例有局部收益；不默认新模型必做或固定0.75 |

初始化候选、完整拟合、评测和保留规则按下节执行；实际模型／数据绑定、无保护S4适配、总GPUh及后续恢复安排在执行前落实。空闲卡不构成增加候选的理由；预算用完而未达标时报告差距，不自动继续扩大范围。

初始化排名使用同口径、未舍入的完整八项均值；任何正提高都更新。精确同分沿SC-CAT依次取较低logical、较低packed、保留当前配置、稳定配置ID；从全部轮次的合法不同配置中保留前两名。MMLU、训练loss或局部误差不替代八项。初始化选优不等于最终验收：成品仍须同时通过本规范MMLU与九项门槛，恢复阶段的综合／MMLU取舍另外固定，不能事后改初始化排名规则。

### 6.1 无保护四阶初始化搜索表

只比较当前类别全部层的S4表示，其余类别保持共同BF16；不在离线初始化轮混入类别蒸馏。统一起点沿SC-CAT：D32、asymmetric encoder128／decoder128、两侧R0、AdamW LR .003、transpose=False、block32；本方案覆盖为**S4、各阶K32、保护0**。原有归一化、BSQ拟合设置及优化器步长参照沿共同规则，模型相关batch／分组按实际适配并记录；不套用旧Qwen gate例外。每轮继承之前已选完整配置，重复结果复用，不展开全组合。

| 顺序 | 沿用的候选 | S4／新模型适配要求 |
| --- | --- | --- |
| 1. 转置 | 全类不转置／全类转置／至多一个逐层混合 | 沿固定train逐层输出MSE提名，再完整拟合及八项比较；新混合配置不拼接两份已拟合bank |
| 2. 旋转 | none、block32／64／128／256、full中的合法候选 | 核完整权重尺寸、实现支持与费用，不做保护回填或静默替换 |
| 3. 向量维度D | 8／16／32／64／128中的合法候选 | **每阶K随D保持K=D、始终四阶**；核完整矩阵布局、batch联动及真实S4消费者支持 |
| 4. encoder宽度 | 128／256 | decoder及其他设置保持当前值 |
| 5. decoder宽度 | 128／256 | 继承已选encoder；四阶decoder实际费用纳入账本 |
| 6. 拟合优化器 | AdamW／Muon | 沿VAE拟合分组与既定更新倍率定义，不套decoder恢复学习率；核真实S4适配 |

本阶段的S=4、每阶K=D、保护0保持固定，不加入阶数或主码位宽扫描。每个新配置从共同BF16 fresh拟合，**四阶各完整10K**并做完整八项；2K／5K只作观察，不提前淘汰。同类别仅并行当前轮候选，轮间等待选择；不同类别可独立并行。已有S2或带保护S4仅供方法参考，其质量、成本、bank或排序不能替代本轮结果；只有完整来源、表示、数据、协议及预算均适用的结果才能直接复用。

按SC-CAT现有名额删除一个保护候选后，每类至多**19个不同完整配置**：初始1＋转置1＋逐层混合1＋旋转5＋D4＋encoder1＋decoder1＋优化器1＋倍率4。删除的保护名额不挪作其它探索；重复、非法或不适用项按共同规则记录，不填满名额。全轮次保留前两名的规则不增加候选数，也不意味着本轮已授权正式恢复。四阶拟合与完整矩阵会改变实际计算量，GPUh须重新估计，不能复制S2或旧带保护S4的费用。

## 7. 恢复、续训与原生导出契约

类别恢复只更新所选可训练字段；若采用累计prefix，范围是所有已压缩类别，不能实际只训当前类却报告prefix。future dense、主码／旋转、embedding/head/norm按所选合同保持。冻结MLP权重仍须让输入梯度通过实际MLP前向。本次复用初始化搜索不自动叠加SC-CAT仍在修订的全部恢复网格，具体恢复范围／节点／预算另行落实。

知识／QA目标须在实际前向生效。本表示没有保护整数或保护scale，不创建对应参数组、优化器状态或部署载荷；原生检查须确认所有目标权重由四阶表示覆盖。历史保护QAT实验的保存／导出证据只适用于旧表示，不能充当新无保护路径的验证。

同一训练64→128之类节点保存并恢复FP32 masters、Adam moments／step、RNG、数据游标、参数名顺序及父／代码／数据身份，保持同一日程；不能从舍入后的部署模型重建一个fresh Adam，冒充精确续训。另一个候选从共同父新起，与同轨迹延长明确区分。

端点评测使用保存后独立进程重建的原生BF16模型，检查strict加载、允许字段／冻结补集、前向有限与实际账本。技术／协议失败停止受影响依赖，不降正式batch、缩关键上下文、跳检查或自动重试；其他独立候选正常推进。成熟路径复用有效证据，只对模型／数据／关键路径变化补最小充分验证。

## 8. model merge的使用边界

端点须有清楚的共同父与生成规则、相同参数名／布局／无保护四阶拓扑，所有声明冻结字段一致。允许合并的字段逐项列出；若选择decoder插值，对同名FP32参数使用统一比例后按原生BF16导出。新表示没有保护整数代理，不能沿用旧decoder＋INT8代理合并配方。Adam／RNG不合并，合并模型不是原优化器轨迹的可精确续训端点；本节仅保留可选方法边界，不将合并加入已确认初始化搜索。

合并后独立fresh、完整八项，入围模型再完成同checkpoint九项；不能相加端点各自最好任务分数，也不按测试逐题或逐层调比例。**同轨迹单seed筛选的改善不证明跨模型／seed／位宽泛化。** 最终完整配方须包括两个端点怎样生成、比例如何确定及全部成本，不能只写“加载一个合并好的模型”。

完成本模型已确认的必做搜索表后，若未经合并已经达标，可结束该模型本阶段的候选探索；是否追加可选合并，由预先声明的批次范围决定。不能仅凭参考起点达标就跳过已确认的必做搜索，也不把可选合并设为无条件必要步骤。
