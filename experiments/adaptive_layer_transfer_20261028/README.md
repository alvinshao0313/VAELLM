# 动态残差阶数的L18／L35基础预算复现

2026-10-28已完成CPU准备、真实GPU两步验证及L18／L35各6000步第三阶训练与基础预算读出，仍只涉及Qwen3-8B的down类别。设计依据与L0数值见[原实验](../adaptive_vector_rvq/README.md)。本页维护不含稀疏payload的基础预算结果；后续复用同一bank的[INT8＋abs005共同cap直接对照](../adaptive_sparse_layers_20261028/README.md)另有唯一正文，两组预算和对照对象不同。

## 固定设计

两层分别复用原有fresh-HF fixed2全部编码、decoder、保护及旋转：实际4096×12288 down矩阵、D32／K48／H128／R0、transpose、双侧block32、256个INT8保护输入列。只新增第三阶，seed2031、batch8192、LR0.003、linear6000，3000／6000步观察并固定6000末节点。每层的未加权／激活加权分配共用同一码本，至多四轮真实zlib长度计费、最后可行轮，不训练第四阶或扫描超参数。

前64篇FineWeb-edu train文档15,183有效token用于激活二阶矩，后64篇15,492 token用于本轮留出读出。完整128篇此前已经观察，不称盲测。保持真实输入sign→forward Hadamard→每输入行能量→repeat128布局，报告各层三个端点各自校准／留出／全量输出误差；全量由SSE和目标能量相加计算，不平均NMSE。不同层的NMSE也不合并成模型质量指标。

此复现沿用原L0预算：每层实际文件＋未物化第四decoder的21,312 B保守预留≤fixed2的19,607,424 B。实际文件只写三个decoder，实际成本与预留分别列。额外第三阶训练不与fixed2等算力；同码本两种分配才是纯分配对照。

原始证据位于输出根`formal_l18/report.json`／`formal_l35/report.json`，核心日志为`formal_l18.log`／`formal_l35.log`，完整紧凑端点位于各层`unweighted_dynamic3/`和`weighted_dynamic3/`。每份报告保存实际命令、源码／输入SHA、目标digest、训练种子、轨迹、配置及退出状态。第三阶bank与前缀误差已用于后续共同cap对照，并保留供该对照的来源复核；原fixed2／初始数据未动。

本次复现说明相同预算下的收益依赖层与分配目标，额外第三阶训练未与fixed2配平算力，128篇train输入此前已见；没有完整模型或下游精度结论。后续[稀疏共同cap结果](../adaptive_sparse_layers_20261028/README.md)使用更高的实际cap且不含第四decoder预留，不能覆盖这里L18未优于fixed2的事实。
