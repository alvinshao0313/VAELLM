# CAT 向量长度与编解码器容量的同源筛选

本轮比较同一真实 `after_o` 边界上的四个 gate 结构，为完整类别压缩提名候选。三个代表层及有限任务读出均只用于筛选，不替代完整低比特模型或九项验收。研究背景见[现行路线](../../docs/experience/records/w25_transfer/2026-10-04_mmlu65_llama31.md#10月29日数值正确性动态阶数与几何校准的递进路线)。

## 配置与入口

共同来源为 `/data/star/VAELLM/qwen_recompression_20261026/C/initial_after_o`，UUID `b63bfe79-3889-40c6-bf66-1d002893f874`，144个已压投影和108个未压MLP投影。固定浅／中／深 `L0/18/35 gate`，拟合此边界的 live dense 权重，不用 HF 权重替代已恢复来源。保护通道取该来源的原CAT统计，四臂共享input64集合与重新编码的INT8值、方向及旋转。

| 臂 | D / K / S | encoder / decoder隐藏宽度 | 每层向量batch |
| --- | --- | --- | --- |
| A | 32 / 32 / 2 | 128 / 128 | 8192 |
| B | 64 / 64 / 2 | 128 / 128 | 4096 |
| C | 32 / 32 / 2 | 256 / 128 | 8192 |
| D | 32 / 32 / 2 | 128 / 256 | 8192 |

四臂实际使用 `asymmetric`，encoder与decoder分别控制；seed与shuffle seed均31，每级10000更新、原CAT日程，每更新每层262144个权重标量。主码率均2bit，采用原CAT三层分组及pooled BSQ entropy。这里没有改用自适应阶数原型的独立逐层熵目标。D变化仍改变向量池、随机映射、BSQ维度及幅度，不能称所有数学条件相同；匹配标量曝光也不等于匹配FLOPs。

- `prepare.py`：CPU绑定来源，保存三层权重、同源up/down、固定保护及数据证据。
- `capture.py`：用原生category-boundary loader重新获取本来源的真实gate输入。只复用预定tokens，不复用旧HF激活。
- `run.py --arm A --steps 10000 --output <独立目录>`：原CAT拟合、原生保存／重载、存储与局部输出读出。B/C/D只替换臂名。
- `probe_model.py`：相同父模型依次替换三层gate，读取固定64道 `auxiliary_train` 的四选项分布；每臂后恢复父模块。

调用者先激活 `bitvae`。准备程序设 `CUDA_VISIBLE_DEVICES=''`，GPU程序显式指定一张空闲卡。输出根为 `/data/star/VAELLM/cat_structure_probe_20261029/`；真实命令与源码SHA在各报告中，不覆盖已完成目录。

局部输入为原预定FineWeb-Edu `sample-10BT` train连续128篇，最大256token，共30675有效token；来源版本、许可、tokens SHA与抽样索引见 `prepared/prepared.json`。这批材料已有观察，不称盲测。两个64篇切片分别记录，只用于检查条件内一致性。

## 2026-10-29 已完成结果

CPU准备4.48秒，真实输入捕获22.07秒。新B/D形状各完成原生两步短验；四个正式拟合均完成双级10000步，外层exit0，12份端点的持久状态及部署权重fresh重载exact，原保护一致。A/B/C/D耗时分别563.54／565.42／564.63／554.88秒；不同卡并行的墙钟不用于宣称结构加速。

每个gate共同逻辑上限为106067456bit。A/C实际105793024bit，B106056192bit，D106067456bit；均包含码、decoder、保护及旋转，encoder不部署。文件容器大小另列在各 `formal_X/report.json`，不是整模型2.6bit验收。

完整原始分布与端点SHA在 `model_probe.json`。C的局部误差较差而此读出略好，说明这两个代理的排序不完全一致；不能用一题差距判优或淘汰，也不能把四选项KL称为全词表能力保持。当前只有三层gate被替换、其余仍含dense投影，没有完整压缩模型或新增正式MMLU／九项分数。

研究审查提名A控制／B长向量两条完整36-gate候选，C保留未决，D暂不追加完整分支；这是一轮有限预算分配，不是容量方向的淘汰结论。各支须从共同after_o重新拟合全部36gate（原CAT M36目标），分别经历相同500步恢复，再拟合本支live up/down与相同后继恢复，不能借另一支的历史donor。新结构上的动态阶数收益必须重新测量。

完整类别入口的随机规则沿原C：基础seed31，实际类别shuffle seed由既有函数派生为gate400031／up500031／down600031，两臂一致。上文三层probe的显式shuffle31仍是其实际条件；不能把M36新分组和派生随机流称为该三层轨迹的逐位复现。

落地有两个明确缺口：现有分叉器只允许未来类别改变K/S，新隔离边界还须显式表达gate D及decoder结构改变，不能冒充原配置精确续训；`vae_batch_size`是全局参数，B的gate用4096时不能把后续D32 up/down也一并减半。按当前单gate实测账本扩至36层，B较A多9474048bit，若其余几何保持原C，预计全投影逻辑位宽约2.49873153对2.49736753；这只是几何估算，最终需真实全模账本。当前asymmetric实际走原生非whole-fused路径，不能因尺寸在融合核上限内就声称用了该核。若缺少D64/K64 packed decoder的模型级反向证据，正式类别恢复前只补B真实恢复两更新，保留正式batch／长度／prefix与未来dense LoRA范围；A沿用有效证据。

完整类别实现代理已确认不消费三层端点或准备阶段的权重／激活副本，M36必须重新拟合原after_o。依收尾授权已删除18份formal／short端点及两份可再生准备张量，共20文件、实际释放1900826624B；精确路径、大小及删除核验在输出根`cleanup.json`。原始报告、核心日志、输入来源与代码SHA以及原after_o／tokens保留；报告中的旧端点路径作为历史身份，不代表文件仍可消费。尚未启动36层重压，不按本次64题挑历史模块合并。
