## 数据、目标与优化条件

只读复用当前Web2048＋Med2048＋原QA128、原始BF16教师缓存和固定来源绑定。原128组按顺序消费，每步Web16＋Med16＋QA8；Web/Med损失等权。64步每源1024题各一次、QA128各四次；128步每源2048各一次、QA各八次。知识／QA域权重各.5。QA保持原gold-prefix全词表静态教师KL，无在线rollout或新教师。

A/C/D继续一次混合的`m=.5t+.5gold`前向KL。B对相同m计算`λ KL(m||p)+(1−λ)KL(p||m)`，知识batch32平均；`λ=mean(min(H(t),log4)/log4)`，t为未混入gold的原始教师。λ不反传，不使用学生／测试信息，不重复混gold。原始128组λ约.2198153–.4666944、均值.3543205，仅为CPU参考。采用FP32有限log-prob计算，不加平滑或新温度。此为[EdgeRazor§3.3](https://arxiv.org/html/2605.04062v1#S3.SS3)的四选项混合目标改造版，k=4而非论文全词表k=16，不称完整复现。

四臂decoder初始LR5e-7；所有参数组乘原500步线性日程`1−(step−1)/500`，64→65不中断数学训练状态。AdamW β(.9,.95)、eps1e-8、WD0、foreach=False、seed137，全部活动参数共同clip1.5。FP32 master／梯度／Adam，原生BF16计算和部署。C/D新增学习率来自既有参数化起点，非本S4最优结论；联合clip和参数化也属于候选配方，不把结果称纯参数数量因果。

C以零初始化FP32 log_delta训练`BF16(source_scale*exp(delta))`，整数／索引冻结。scale舍入前后有限且正，直接回写学到的BF16 scale，不重标定整数。D从原signed-int8数值初始化FP32 master，clamp[-128,127]、ties-to-even round硬前向／STE反向，乘冻结原BF16 scale；仅导出uint8硬整数。记录浮点变化、相邻硬变化、相对初态净变化及首次硬变化步号。低预算未跨量化阈值不单独作阴性结论。

主码、保护位置／数量、旋转、embedding/head/norm冻结。252投影均保持四阶，logical=packed4.094031292459239bpw，含原decoder／保护／旋转开销，embedding/head不计投影账本；训练代理及Adam不进入部署。格式中的decoder_only历史字段沿用原生序列化接口，真实活动范围写入distill_stage.recipe及mutable_native_names，不以该字段误报保护冻结。
