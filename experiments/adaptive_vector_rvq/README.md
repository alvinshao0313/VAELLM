# Linear 内向量自适应残差阶数

2026-10-27，隔离原型。先检验固定两阶与向量自适应 1–4 阶的存储／重构取舍；不改公共 CAT、VAELinear 或活动实验。跨 Linear／类别共享编解码器暂不加入。

## 配对设计

- 预先固定 Qwen3-8B 的 `model.layers.{0,18,35}.mlp.down_proj`；覆盖浅、中、深层，但不是全部 36 层或完整模型验收。
- 两臂从同一 HF BF16 dense 权重重新拟合；G 成品只提供固定的 256 个保护输入索引和旋转规格，不作为重构教师或复用已经恢复的主码。
- 每个 Linear、每个 stage 的编解码器独立，`D=32, K=48, H=128, R=0`、LayerNorm、SiLU、symmetric decoder、BSQ/new_quant。保持同一保护、转置、旋转与向量布局。
- 两臂共用一次训练的第一阶，之后冻结第一阶的 decoder、编码与规范化结果。
- **fixed2**：全部向量训练第二阶，固定训练 6000 步。
- **adaptive4**：第二、三、四阶分别只训练当前高残差活跃集合，每阶 2000 步；退出后不再进入后续阶段。
- 第一阶 2000 步，batch 8192；AdamW、LR 0.003、betas=(0.9,0.95)、weight decay=0、linear schedule、warmup=0，其余 BSQ 损失参数沿现有配方。这里使用 linear；此前讨论中提到 cosine 是误记。
- 每臂包含第一阶各为 8000 个优化更新；实际共用第一阶，因此每个矩阵合计执行 14000 次更新。相同 batch／D／K 下近似等训练计算量，但阶段重置、活跃集合及学习率轨迹不同，不能称逐步完全相同的优化过程。
- fixed2 的 2000／4000 步读出是 6000 步调度的中间轨迹，不是独立短调度的完整控制。正式比较固定末节点，不按下游结果择优。

本轮短拟合预算低于旧正式 CAT 常用的每阶 10000 步。未收敛、无收益均不能直接证明方法上限。

## 由完整预算决定门控数量

每个 Linear 单独与 fixed2 配平，不在层间移动预算。令 `N` 为去掉保护通道后的向量数，`K=48`。先按实际 BF16 decoder 参数与张量类型计算：

```text
fixed2_bits = fixed_overhead + 2*N*K + decoder_1_bits + decoder_2_bits
adaptive_bits = fixed_overhead + K*(N+m2+m3+m4)
                + 8*ceil(N/4) + sum(decoder_1_to_4_bits)
```

`fixed_overhead` 包括两臂相同的 INT8 保护值、scale、indices、旋转符号及实际启用的其他持久状态。当前独立二进制格式还完整计入两臂各 16 KiB 的定长元数据头，实际文件大小必须与账本相等；不会以 pickle 容器的估算字节替代实存。张量有效载荷与容器头分别报告。

在满足 `adaptive_bits <= fixed2_bits` 下，由可用额外码数确定一个保留率 `rho`：

```text
m2 = floor(N*rho)
m3 = floor(N*rho*rho)
m4 = floor(N*rho*rho*rho)
```

这是预先规定的单参数活动数量方案，不声称它是最佳阶数分配；取整留下的一两条码优先补到较早阶段，并记录这项整数修正。每阶在上一级活跃集合内按当前累计重构的向量 MSE 降序选前 `ms` 个；相同分数按原向量编号确定顺序。实现除以固定的原始矩阵方差只为报告尺度一致，不改变该 Linear 内排序，也不按每个向量自身能量重加权。阈值是这一排序的分位点，由预算确定，不手工根据测试表现调阈值。每阶训练后用真实导出精度解码，更新累计残差，再筛下一阶。

实际 down 的 `N=1,540,096`、每阶 BF16 decoder 为 10,656 参数时，仅长度标记就占 0.0625 bit／未保护权重；额外两个 decoder 也需计费。因此平均阶数必须低于 2，而不是沿用两阶码预算后另外添加元数据。该预算下 `rho` 约为 0.528，约 47.2% 向量停在第一阶，是较强的重分配假设；负结果只能否定这一配额与拟合条件，不能否定更集中于第二阶的其他分配。

## 紧凑码流与数值契约

- `length-1` 使用 2bit，四个向量共用一字节；表示 1、2、3、4 阶，不包含 0 阶。
- 每阶按原向量顺序只保存 `length >= stage` 的编码；K48 每条码恰为 6 字节，未使用的尾阶不占位。
- 活跃位置由长度表唯一恢复，不额外保存每个向量的坐标索引。若格式另加偏移表，必须真实记账。
- 不活动的阶段完全跳过，包括 decoder bias 和融合的 stage mean，不能用零 latent 代替缺席。
- 规范化和 BSQ 尺度沿原核心实现融合进各 stage decoder；融合后的 decoder 使用已有 0/1 码语义。
- 门控使用实际部署精度的累计重构；此前阶段参数、码及已退出集合在后续训练中冻结。

### 统一阈值的固定前缀诊断

`diagnose.py` 只读 L0 的既有 fixed2 成品，实际解码全部 1,540,096 个向量的 BF16 第一／二阶累计结果，再用 FP64 统计逐向量误差。2026-10-27 18:56 完成，耗时 5.31 秒，原文件身份与前缀误差均复现；没有重新训练。证据在输出根 `repair_20261027/threshold_diagnostic/{report.json,per_vector_errors.pt}`，后者用于随后固定码本分配诊断。

第二阶对全部向量都有正的重构收益。按共同归一误差阈值 τ 定义 `active2=e1>τ`、`active3=(e1>τ)&(e2>τ)`，完整预算能够容纳的最小 τ 为 **0.158946496211**：93.9781% 进入第二阶、1.39394% 进入第三阶；此时尚未给第四阶留码，已使用除 2 B 外的全部 fixed2 预算。若预算由某种合法第四阶数量填满，τ 的必要区间为 [0.158946496211, 0.162955202035]；这只是前两阶固定时的预算必要条件，不是第四阶真实可行性证明。

在最小 τ 处，已经停在一／二阶的向量贡献整体 NMSE **0.077921315408**，仍高于 fixed2 总误差 **0.074768634072**。由于本次所有向量的 `e1>e2`，提高 τ 只会增加这部分退出误差；因此在这两个前缀固定、全四个 decoder 均计费的条件下，即使后两阶能完美重构，共同阈值也无法胜出。该结论不限制重新训练活跃集合后的表示，也不限制以追加一阶的实际收益而非剩余误差分配。

为分开“共同阈值规则”与“动态阶数的表示能力”，`ideal_bound.py` 将第三／四阶误差均设为零，构造只会优于任何真实尾级的数学放松。对每个 λ 计算 `argmin_s(e_s+λs)`，以完整预算 `M=3,008,917` 个码向量为约束，报告实际可行误差和对偶下界 `Σmin_s(e_s+λs)-λM`，不假定边际收益递减。CPU 1.42 秒实测：可行误差／下界均为 **0.076938261304**（间隙 −1.39e−17，属于 FP64 舍入），高于 fixed2 约 **2.90%**；长度计数 `[160799,1289773,89524,0]` 恰好用满码数预算。因此没有再训练这套冻结前缀的 dense 第三／四阶。证据在 `repair_20261027/ideal_bound/`；`ideal_lengths.bin` 只是数学放松的分配，报告的完整字节数是对应预算计算，不是已训练／导出的四阶模型文件。

### 实际压缩长度计费与真实第三阶

`entropy_budget.py` 最多执行四轮“给定码数预算的 λ 分配 → 长度流真实 zlib6 压缩 → 重算预算”，不按质量增加候选。重复或不变的码数预算即停止，选最后一份完整账本可行的候选；压缩率随分配改变，因而不宣称这是非分离存储成本下的全局最优。

## 10月29日：高效并行实现方案与讨论边界

用户要求编解码器优化的效率与方法有效性一起考虑，实现方案须先说明／讨论。当前[整模型桥接草稿](../adaptive_native_bridge_20261029/README.md)仅负责短码流消费、可导恢复和保存重载，尚未运行，也不是高效编解码器拟合方案。本次先讨论下面的首版架构，再开展对应实现；没有并行性能提升实测。

推荐保留当前正例的算法顺序：各层依次拟合可用残差阶数，随后按实际存储预算分配长度。当前weighted_dynamic3的第三阶对全向量拟合，后续才选择保留行；把拟合改为只训练当前active集合会改变训练样本和轨迹，不能当作等价提速。

- **拟合按层分组并行。** 同阶段、同D/K/H及decoder结构的层可组织为`[batch=8192, model_count, D=32]`，复用已有`ParallelLinear`批量GEMM。层组分布到实际可用GPU，各层参数独立；同一层后阶等前阶产生真实残差后再训，类别间恢复的依赖也保持。分组数用实际耗时／峰值显存选择，不承诺4或8必定最优。
- **完整损失必须保持每层独立。** 当前`BSQ.soft_entropy_loss`会跨模型轴平均概率，直接把独立原型的`parallel_layers`调大并不等价。新并行拟合只批量计算encoder/decoder，层内归一化、per-sample/codebook entropy、MSE/commit及各自shuffle／尾批／Adam／LR时序仍按独立reference计算，再求和；不以共享概率改变损失。已有CAT自身的group语义不在本轮自动改写。
- **路由固定后紧凑解码。** 后续模型恢复按真实`(层,stage,decoder规格)`组织活跃行，复用现成stage-major短码流。每层每阶只计算实际存在的码；末批处理只涉及有效行，缺席stage连bias／mean也不贡献。decoder输出可分组计算，最终仍按原文件的阶段顺序BF16相加，不直接换成当前原生融合的FP32累加。冻结码／路由时不每个optimizer step重新排序压缩长度；decoder或训练模式变化后必须使解码缓存失效。
- **效率验证与质量证据分开。** 先以已有L18/L35真实残差做独立与双层分组的同初始化、同更新预算、同batch对照；验证数学目标、梯度／更新及保存链后，测稳态更新、完整拟合／编码／分配／保存耗时与峰值显存。比较达到同局部误差／同存储的总成本，后续才是完整九项同条件的总流程成本。不重复已有三层方法有效性对照，也不以少算行数宣称实际加速倍数。

现L18动态文件的三级实际行数为1,540,096／1,515,360／126,833，较全三阶少约31.1%，但较固定两阶多约3.3%；它说明紧凑解码的工作量范围，不等于GPU用时或编解码器拟合成本下降。周期性重分配、联合训练以及共享decoder另属后续算法选项，须用独立对照说明收益和代价，不混入首版等价并行优化。
